# Elysium Mist Retreat | Luxury Eco-Resort

![Elysium Mist Retreat](https://images.unsplash.com/photo-1586348943529-beaae6c28db9?w=1920&q=90)

A high-converting, performance-optimized, and visually stunning landing page for a premium tourism resort in Munnar, Kerala. Built as a portfolio anchor demonstrating advanced frontend UX architecture.

## ✨ Features

- **Immersive Scroll Animations**: Powered by GSAP & ScrollTrigger. Includes parallax hero images, pinned horizontal scrolling for the Villa showcase, and staggered text reveals.
- **Modern Tech Stack**: Next.js 16 (App Router) combined with the latest Tailwind CSS v4 for lightning-fast compilation and custom CSS variable token management.
- **Lead Capture Integration**: A responsive bottom-sheet/side-drawer built with `react-hook-form` that dynamically generates pre-filled WhatsApp inquiry messages to directly connect guests with the reservation team.
- **SEO & Performance Optimized**: Utilizes `next/image` with proper sizing, responsive loading, and comprehensive JSON-LD schema metadata for maximum visibility.
- **Mobile-First Luxury UI**: Custom typography (`Cormorant Garamond`, `DM Sans`, `Playfair Display`), bespoke color palettes, and elegant glassmorphism elements tailored for high-end hospitality UX.

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🛠 Tech Stack

- [Next.js App Router](https://nextjs.org/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [GSAP (ScrollTrigger)](https://gsap.com/)
- [React Hook Form](https://react-hook-form.com/)
